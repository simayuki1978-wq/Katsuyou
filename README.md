# Japanese Conjugation Learning App

## Overview
A web-based application designed to help learners master Japanese verb and adjective conjugations. The app retrieves learning data from Google Sheets and provides multiple study modes to support effective practice and review.

## Features
- 📖 Scrollable conjugation tables
- 🃏 Flashcard learning mode with progress persistence
- 🎯 Quiz mode with score and combo tracking
- 🔄 Weak-point review mode for targeted practice
- 🌙 Dark mode support

## Built With
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Sheets as a CSV data source

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Select a learning mode from the main menu.

## Data Management
Learning data is maintained in Google Sheets and loaded dynamically via CSV.
